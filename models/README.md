# Model Artifacts Directory

This directory will contain trained model files after running the analysis.

## Files Generated

After running `python run_analysis.py`, the following files will be created here:

- **dropout_prediction_model.pkl** - Trained classification model (best performing model)
- **feature_scaler.pkl** - StandardScaler object for feature normalization
- **feature_names.pkl** - List of feature names in correct order
- **scale_features.pkl** - List of features that need scaling

## Usage

### Load the Trained Model

```python
import joblib

# Load model and supporting artifacts
model = joblib.load('models/dropout_prediction_model.pkl')
scaler = joblib.load('models/feature_scaler.pkl')
feature_names = joblib.load('models/feature_names.pkl')
scale_features = joblib.load('models/scale_features.pkl')

# Now you can make predictions
predictions = model.predict(X_new)
```

### Using the Prediction Script

The easiest way to use the trained model is through the prediction script:

```bash
# Interactive mode
python predict.py --interactive

# Batch prediction
python predict.py --student_file data/new_students.csv --output_file predictions.csv
```

## Model Details

The model saved here is selected automatically as the best performing model based on AUC-ROC score from among:
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting

See `results/ANALYSIS_REPORT.md` for detailed performance metrics.

## Note

These files are excluded from version control (via .gitignore) because:
1. Model files can be large (several MB)
2. They can be regenerated by running the analysis
3. Git is better suited for code, not binary artifacts

To share your models with others, consider:
- Using Git LFS (Large File Storage)
- Hosting on model registries (MLflow, Weights & Biases)
- Cloud storage (S3, Google Cloud Storage)
