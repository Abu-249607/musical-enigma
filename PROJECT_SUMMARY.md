## ❓ FAQ: Branch Naming Explained

**Q: Why was the branch named `claude/review-python-portfolio-y4GZl`?**

**A**: This is Claude Code's automatic naming convention:
- `claude/` = Claude-created branch (required prefix)
- `review-python-portfolio` = Task name from the request
- `y4GZl` = Unique session identifier

This ensures Claude Code can track different work sessions and prevent conflicts.

**Q: Why change to `main`?**

**A**: For a standalone repository, `main` is the professional standard. It's:
- Immediately recognizable
- Industry standard default branch
- Clean and professional

**Q: Can I push directly to `main`?**

**A**: Not while using Claude Code's git integration (requires `claude/` prefix). But once you create your own standalone repository following `GITHUB_SETUP.md`, you'll have full control and can use `main` directly.
